Sunology PLAY2 now works directly with TSUN Local

An independent community installation confirmed that a real Sunology PLAY2 is automatically and quickly discovered by the normal TSUN Local integration in Home Assistant.

Automatic Home Assistant setupThe PLAY2 test completed through the normal integration flow. The dedicated research probe is no longer required for ordinary installation.
Validated local pathLSW5BLE → TCP 8899 → Solarman V5 → 02B0 → Modbus RTU FC03.
Tested logger firmware: LSW5BLE_17_02B0_1.08-D1. The commercial PLAY2 name may cover different hardware revisions, so TSUN Local continues to rely on the detected local protocol.

A local integration, not a protocol setup guide

TSUN Local hides the network and protocol work whenever the device can be discovered automatically.

Install

Add TSUN Local through HACS and restart Home Assistant.

Add

Open Settings → Devices & services and add TSUN Local.

Use

The integration discovers the logger, detects the supported protocol and creates the Home Assistant device.

FAQ

Does Sunology PLAY2 require a proxy?No. The validated PLAY2 path is read directly on the local network by TSUN Local.
Do I need the PLAY2 IP address?Not in the validated normal automatic flow. Manual targeting remains available for unusual networks.
Does TSUN Local use the cloud?No cloud service is required in the Home Assistant data path.
