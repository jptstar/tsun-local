TSUN Local — Home Assistant integration for TSUN micro-inverters

TSUN Local connects compatible TSUN solar micro-inverters directly to Home Assistant over the local network for local photovoltaic monitoring without a proxy or cloud dependency.

Local. Read-only. No cloud dependency. No proxy.

Add TSUN Local to HACS View on GitHub Releases

Local solar monitoring in Home Assistant

TSUN Local is an independent open-source integration focused on direct LAN access to compatible TSUN micro-inverters. Telemetry is read locally and presented as native Home Assistant entities.

☀️ PV telemetryVoltage, current, power, daily energy and total energy for detected PV inputs.
⚡ AC telemetryVoltage, current, frequency, power and energy counters.
🚨 DiagnosticsLocal communication status, alarms and device/logger information.
🔒 Read-onlyNo inverter configuration writes are implemented.

TSUN micro-inverter compatibility

Compatibility is organized by local protocol family and validated on real hardware where stated. The project evolves as additional devices and firmware versions are tested.

FamilyValidated referenceNotes
TITAN / 1511TSOL-MP3000Validated on real hardware; up to six PV inputs in the current map.
GEN3 PLUS / 02B0TSOL-MX500Validated on real hardware; protocol-family support covers additional compatibility candidates.
GEN3 / 1097ExperimentalExperimental protocol support is available on the current development branch and requires broader real-device validation.

A model not listed here is not automatically unsupported. See the repository README for the current compatibility matrix and protocol status.

Install with HACS

TSUN Local can be installed as a custom Home Assistant integration through HACS. Add the repository, install the latest release, restart Home Assistant, then add TSUN Local from Devices & services.
