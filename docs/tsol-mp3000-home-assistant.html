What TSUN Local exposes from the MP3000

The TSOL-MP3000 is a validated reference device for TSUN Local's TITAN / 1511 support. Home Assistant entities are created from the data actually returned by the inverter.

☀️ Six PV inputsVoltage, current, power, daily energy and total energy for the detected MP3000 PV inputs.
⚡ AC productionAC voltage, current, frequency, power and energy information.
🚨 Readable alarmsActive inverter alarms can be presented as localized descriptions with stable diagnostic codes.
📡 CommunicationOnline state, last successful communication, duration and consecutive failures.
🧩 Device informationFirmware and inverter information where exposed by the native 1511 blocks.
🛡️ Advanced diagnosticsAdditional read-only diagnostics remain disabled by default until you choose to enable them.

Validated local protocol path

The MP3000 support is based on repeated read-only captures from real TSOL-MP3000 hardware. Native 1511 blocks for inverter settings/status and PV1 through PV6 have been read successfully.

TSUN TSOL-MP3000 → local network → TITAN / protocol 1511 → native read-only blocks → TSUN Local → Home Assistant
✅ Real-device validation includes PV1 through PV6. The native A3/A4 blocks have been read successfully on the physical MP3000, including the per-input daily-generation positions.

Read-only by design

TSUN Local is intended for monitoring. It does not implement inverter configuration writes, country/profile changes, grid-protection writes or inverter control commands.

Normal Home Assistant useProduction, energy, communication, alarms and device information remain the everyday interface.
Expert diagnosticsAdditional field-validation and grid-related values stay read-only and are disabled by default where appropriate.
