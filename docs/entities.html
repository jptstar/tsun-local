TSUN Local entities for Home Assistant

TSUN Local exposes a compact everyday interface and keeps expert diagnostics out of the way. The exact entity set depends on the detected protocol, PV inputs and data returned by the inverter.

1511 · TITAN / TSOL-MP3000

Validated with up to six dynamically detected PV inputs. In addition to everyday telemetry, the adapter exposes firmware, inverter temperatures, read-only grid-protection diagnostics and field-validation data.

PV inputsUp to 6 dynamic inputs with voltage, current, power and energy.
Grid diagnosticsRead-only threshold, recovery and timing values; advanced entities disabled by default.
Alarm coverage224 source positions preserved through the compact alarm interface.

1097 · GEN3 / GEN3 PLUS

Experimental protocol support. Up to six PV inputs can be created dynamically. Semantics that still require broader real-device confirmation remain explicitly marked as experimental.

Advanced diagnostics

Advanced entities are intentionally disabled by default. In Home Assistant open Settings → Devices & services → TSUN Local → Device → Entities → Disabled entities and enable only the diagnostics you need.
