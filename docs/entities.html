How 1511 alarms appear in Home Assistant

The MP3000 alarm interface stays compact: active positions are decoded inside two everyday entities, while the fourteen original words remain available as optional expert diagnostics.

🚨 Inverter alarmA problem binary sensor that turns on when an alarm position is active. Its attributes list the active localized names and stable local codes.
🔢 Active alarmsCounts every active position, including positions whose exact physical meaning is still awaiting validation.
🧰 Fourteen raw wordsFour inverter words, four secondary words and six PV words. They are disabled by default and intended for advanced diagnosis.
