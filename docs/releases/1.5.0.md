# TSUN Local 1.5.0

TSUN Local 1.5.0 gives the TSOL-MP3000 a complete, clear alarm interface in Home Assistant while keeping the integration fully local and read-only.

## Highlights

- **All 224 MP3000 alarm positions are included.** Every active position is counted and displayed.
- **12 functional mappings are validated on hardware:** low PV input voltage and PV DSP faults for PV1 through PV6.
- **212 positions remain available with neutral local codes** until their exact functional meaning is physically validated.
- A new **Active alarms** sensor shows the current count, localized names and stable TSUN Local codes.
- The existing **Inverter alarm** binary sensor now carries the same compact active-alarm details.
- The fourteen complete raw alarm words remain available as advanced diagnostics and are disabled by default.
- Alarm presentation is available in all eight TSUN Local languages.

## A cleaner Home Assistant alarm interface

The normal device page exposes one clear inverter alarm state and one active-alarm count instead of creating 224 permanent entities. When an alarm is active, its localized name and stable local code are available in the entity attributes.

The complete raw alarm words are still available for advanced diagnostics. They are disabled by default so normal Home Assistant installations stay uncluttered.

## Explicit validation status

The complete local catalogue contains:

| Local range | Positions | Status |
|---|---:|---|
| `A001`–`A064` | 64 inverter positions | Physical validation required |
| `A065`–`A128` | 64 controller positions | Physical validation required |
| `A129`–`A224` | 96 PV positions | 12 validated · 84 require physical validation |

Unknown positions are never discarded and never assigned a guessed functional meaning. They use clear neutral wording until repeatable hardware validation is available.

## MP3000 low-solar observation

The MP3000 position observed with raw value `8192` during dawn, dusk and very low irradiance remains included in the active-alarm count and receives a neutral local code. When it is the only non-fault observation, the separate operating-state entity continues to report **Standby — low solar input**. Its exact functional meaning remains pending physical validation.

## Languages

The active-alarm presentation is available in:

- English;
- French;
- German;
- Dutch;
- Italian;
- Spanish;
- Polish;
- Simplified Chinese.

These texts are independent TSUN Local wording based on confirmed functional meanings. They are not represented as vendor-certified terminology.

## Documentation

- Updated the main README and all seven localized READMEs.
- Added the complete MP3000 entity summary and alarm architecture to the entity reference.
- Updated the project website with the new alarm presentation and explicit validation counts.
- Kept the HACS metadata and installation flow aligned with Home Assistant 2026.3.0 or later.

## Safety

- All alarm data is read locally from the inverter.
- All access remains read-only.
- No inverter configuration write has been added.
- No grid-protection setting write has been added.
- No inverter control command has been added.
- No cloud service or proxy is required in the Home Assistant data path.

## Compatibility

- **1511 / TITAN:** validated on TSOL-MP3000.
- **02B0 / GEN3 / GEN3 PLUS:** validated on TSOL-MX500.
- **1097 / GEN3 / GEN3 PLUS:** experimental.

Home Assistant **2026.3.0 or later** is required.
