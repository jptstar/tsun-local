# TSUN Local 1.5.2

TSUN Local 1.5.2 improves 02B0 compatibility following Sunology PLAY2 field testing and adds a privacy-safe way to distinguish devices in communication logs.

## Highlights

- **PLAY2 / LSW5BLE 02B0 field confirmation:** a real Sunology PLAY2 with firmware `LSW5BLE_17_02B0_1.08-D1` returned a valid Modbus RTU FC03 response inside Solarman V5 on TCP 8899.
- **Explicit 02B0 sensor-list selector:** every 02B0 request now sends `sensor_list=0x02B0`, matching the successful PLAY2 field probe instead of relying on the previous `0x0000` default.
- **Privacy-safe device labels in logs:** when the local logger exposes the micro-inverter serial number, common communication logs use only its first three alphanumeric characters, for example `TSUN device [Y47]`.
- **Cross-protocol behavior:** the short serial prefix is implemented in the common coordinator and therefore applies to 1511, 02B0 and 1097 devices.
- **Diagnostics remain privacy-conscious:** the complete inverter serial number, logger SN, MAC address and network address remain redacted from exported diagnostics; only the short inverter serial prefix may be included.

## Sunology PLAY2 status

The local transport path is no longer unknown for the tested unit:

```text
Sunology PLAY2
  → LSW5BLE logger
  → TCP 8899
  → Solarman V5
  → sensor list 0x02B0
  → Modbus RTU FC03
```

The field probe successfully read register `0x3000` with a valid Modbus CRC using the real Monitoring SN. The same 02B0 selector is now used by TSUN Local itself.

This release does **not** yet mark the PLAY2 as fully validated in Home Assistant. Full compatibility will be promoted only after a direct TSUN Local installation confirms the normal telemetry blocks and entities on the device.

## Compatibility

- **1511 / TITAN:** validated on TSOL-MP3000.
- **02B0 / GEN3 / GEN3 PLUS:** validated on TSOL-MX500; PLAY2/LSW5BLE protocol path field-confirmed and awaiting direct Home Assistant validation.
- **1097 / GEN3 / GEN3 PLUS:** experimental.

## Safety

- Local, read-only polling only.
- Modbus FC03 reads only for the PLAY2/02B0 path.
- No inverter configuration writes.
- No provisioning changes.
- No cloud service or proxy is required in the Home Assistant data path.
