# TSUN Local 1.5.3-beta.1

This beta unifies the alarm interface across the three supported local protocol families.

## Alarm catalogues

- **1511:** 224 stable alarm positions using `1511-A001` through `1511-A224`.
- **02B0:** 64 stable alarm positions using `02B0-A001` through `02B0-A064`.
- **1097:** 64 stable alarm positions using `1097-A001` through `1097-A064`.
- Every active alarm now uses the same presentation: `Description (PROTOCOL-Axxx)`.
- The protocol-position code is shown for both identified and unidentified alarms.
- Known GEN3 / GEN3 PLUS event and fault names are decoded for 02B0 and 1097; unknown and reserved positions keep neutral wording instead of guessed meanings.

## Home Assistant

The compact alarm interface is now common to 1511, 02B0 and 1097:

- **Inverter alarm** — problem binary sensor.
- **Active alarms** — current number of active alarm bits.
- **Active alarm names** — localized alarm descriptions with their stable protocol-position codes.
- Complete raw alarm words remain available as advanced diagnostics without creating one entity per bit.

Technical entity IDs remain stable in English. Alarm descriptions are available in English, French, German, Spanish, Italian, Dutch, Polish and Simplified Chinese.

Examples:

- `Grid undervoltage (02B0-A014)`
- `Unidentified inverter alarm (1097-A041)`
- `PV1 input voltage too low (1511-A137)`

## Safety

Alarm handling remains local and read-only. This beta does not add inverter configuration, protection-setting or control writes.
