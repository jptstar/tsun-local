# TSUN Local 1.6.1-beta.6

This beta keeps the validated beta.5 daily-energy handling unchanged and fixes logger Wi-Fi RSSI freshness across all protocol families.

## Logger Wi-Fi signal

- Preserve the last valid logger RSSI across one transient five-minute HTTP refresh miss.
- After two consecutive RSSI refresh misses (about 10 minutes), mark **Logger Wi-Fi signal** unavailable instead of keeping an indefinitely stale value.
- Never synthesize `0%` for a failed RSSI read.
- Restore the real RSSI immediately on the next successful logger HTTP read.
- Apply the same common logger-metadata policy to 1511, 02B0 and 1097.

## Daily energy retained from beta.5

- Home Assistant local midnight remains the only displayed day boundary.
- Daily AC/PV energy continues from monotonic total-energy deltas and remains protected from hardware counter resets at sunrise or around 18:00.
- No protocol register mapping or device write behavior is changed.

## Validation

- The complete unit-test suite and beta source checks passed before publication.

## Safety

TSUN Local remains local and strictly read-only. This beta changes only Home Assistant-side logger metadata freshness.
