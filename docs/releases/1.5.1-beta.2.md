# TSUN Local 1.5.1-beta.2

This beta corrects the entity-localization regression found after `1.5.1-beta.1`.

## Fixed

- Removed the unvalidated MP3000/1511 **Power level (candidate)** entity (`output_coefficient_candidate`, register candidate `0x07EC`).
- Kept all technical entity IDs and unique IDs in stable English.
- Added/verified translated display names for the ten new MP3000 field-validation entities in English, French, German, Spanish, Italian, Dutch, Polish and Simplified Chinese.
- Verified that the complete 224-position MP3000 alarm catalogue keeps stable `A001`–`A224` codes while alarm names are localized in the same eight languages.
- Added regression tests requiring every canonical Home Assistant entity name to exist in all eight translation files.
- Added upgrade cleanup so the removed beta-only entity is deleted from the Home Assistant entity registry if it existed previously.

## Unchanged

- The 224-position alarm architecture and the fourteen raw alarm source words are unchanged.
- The Wi-Fi logger fallback fix and the MP3000 field-validation diagnostics from beta.1 remain included.
- All inverter access remains local and read-only.
