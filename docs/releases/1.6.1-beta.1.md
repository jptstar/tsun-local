# TSUN Local 1.6.1-beta.1

This beta focuses on communication resilience without reducing the validated register coverage or changing the decoded entities.

## Communication resilience

- 1097 now reuses one TCP session across the normal polling cycle, retries one failed block once on a fresh connection, and protects daily energy counters against transient post-reconnect resets.
- 02B0 now keeps the exact existing fast, alarm, and diagnostic register blocks while reusing one TCP session across a healthy polling cycle and retrying one failed block once on a fresh connection.
- 1511 now keeps the exact existing fast, alarm, and diagnostic native blocks while reusing one TCP session across a healthy polling cycle and retrying one failed block once on a fresh connection.
- Requests remain strictly sequential and continue to use the existing per-logger FIFO.
- Adaptive polling and the existing offline/failure thresholds are unchanged.
- Alarm and diagnostic reads remain best effort so a non-critical block does not unnecessarily invalidate otherwise valid telemetry.

## Regression safety

- No validated 02B0 register range has been removed or merged.
- No validated 1511 register range has been removed or changed.
- Existing decoding, entity keys, protocol framing, and Home Assistant behavior are retained outside the targeted resilience fixes.
- Dedicated regression tests verify unchanged register coverage, healthy single-session polling, and reconnect/retry behavior.
- The beta publication runs the complete unit-test suite, HACS validation, and Home Assistant Hassfest before creating the prerelease tag.

## What to test

Please especially watch:

- regular sensor availability over several hours;
- recovery after temporary Wi-Fi/logger communication loss;
- whether communication still flips to Degraded/Offline unnecessarily;
- AC/PV daily energy values after a reconnect;
- alarms, firmware, temperature, PV inputs, and advanced diagnostics remaining unchanged.

If something behaves differently from 1.6.0, please attach a Home Assistant diagnostic taken shortly after the event.

## Safety

TSUN Local remains local and read-only. This beta does not add inverter configuration or control writes.
