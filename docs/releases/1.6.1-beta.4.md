# TSUN Local 1.6.1-beta.4

This beta focuses on the logger Wi-Fi signal behavior observed on TITAN / 1511 hardware while retaining the communication-resilience and energy-restoration changes from the previous 1.6.1 betas.

## Logger Wi-Fi signal

- Preserve the last valid logger Wi-Fi signal when a periodic local HTTP read temporarily fails instead of publishing a false `0%`.
- Retry the logger RSSI once after the first successful inverter protocol refresh when the initial Home Assistant startup metadata read did not contain a signal.
- Accept firmware variants in strict priority order: `cover_sta_rssi`, `sta_rssi`, `wifi_rssi`, then `wifi_signal`.
- Keep logger RSSI independent from inverter online/offline state and adaptive polling decisions.

This specifically targets the MP3000 / 1511 case where inverter polling remained healthy while the logger Wi-Fi entity became `Unknown` or dropped to a misleading `0%`.

## Communication resilience retained

- 1511, 02B0 and 1097 persistent healthy-cycle TCP session reuse remains unchanged.
- The bounded single reconnect/retry remains unchanged.
- Per-logger FIFO and adaptive polling remain unchanged.
- No validated register range is changed or removed.

## Energy behavior retained

- Daily energy restoration and local midnight rollover from beta.3 remain unchanged.
- Daily energy can reset locally to `0` while the inverter remains offline overnight.
- The first fresh daily-energy value is published immediately when the inverter returns.
- Total energy remains preserved while offline.

## What to test

1. On MP3000 / 1511, watch **Logger Wi-Fi signal** for several hours and across low-light/offline periods.
2. Confirm a transient logger HTTP failure no longer creates a false `0%` drop.
3. Restart Home Assistant and verify the logger RSSI appears promptly once the local logger page becomes readable.
4. Confirm inverter communication remains stable and unaffected.
5. Keep checking 02B0 and 1097 for regression-free behavior.

## Safety

TSUN Local remains local and read-only. This beta adds no inverter configuration or control writes.
