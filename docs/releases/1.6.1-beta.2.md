# TSUN Local 1.6.1-beta.2

This beta extends the 1.6.1 communication-resilience work with a focused fix for Home Assistant restarts while an inverter/logger is already offline or sleeping.

## Energy state after restart

- AC and PV energy counters can restore their last valid Home Assistant state when the first protocol poll after a restart cannot reach the inverter.
- Total-energy counters remain available with their last valid value while the inverter is offline.
- An energy entity with neither a current value nor a valid restored value is now unavailable instead of appearing as `Unknown`.
- The behavior is implemented in the shared sensor layer for 1511, 02B0 and 1097.

## Daily-energy rollover

- Every `*_energy_today` entity is reset locally to `0 kWh` at local midnight, including while the inverter is sleeping/offline.
- If Home Assistant starts on a new day while the inverter is still offline, a restored daily value from the previous day is immediately replaced by `0 kWh`.
- Total-energy counters are never reset locally.
- After a local midnight reset, the zero is retained until two successful protocol updates have been observed, preventing a stale previous-day value from briefly reappearing during wake-up/reconnection.

## MP3000 / 1511 offline presentation

- The six validated TITAN/MP3000 PV entity sets are created consistently even when Home Assistant starts while the logger is asleep, so PV1 does not behave differently from PV2-PV6 solely because no live topology read was possible at startup.
- The 1511 protocol register map, decoder, transport, retry policy and dynamic PV-count logic remain unchanged.

## Communication resilience retained from beta.1

- 1097, 02B0 and 1511 keep the resilient single-session polling and one bounded reconnect/retry introduced in 1.6.1-beta.1.
- Existing per-logger FIFO and adaptive polling behavior remain unchanged.
- No validated 02B0 or 1511 register ranges are removed or merged.

## What to test

Please especially test these cases:

1. Restart Home Assistant while an MX500/02B0 is already offline.
2. Restart Home Assistant while an MP3000/1511 is asleep because of low light.
3. Verify that total AC/PV energy retains its last valid value.
4. Verify that daily AC/PV energy is `0 kWh` after the day changes while the inverter remains offline.
5. Verify that instantaneous voltage/current/power values stay unavailable while offline.
6. Verify normal recovery after sunrise/reconnection without artificial energy drops or a return to yesterday's daily value.

If anything differs from the previous stable behavior, please capture a Home Assistant diagnostic shortly after the event.

## Safety

TSUN Local remains local and read-only. This beta adds no inverter configuration or control writes.
