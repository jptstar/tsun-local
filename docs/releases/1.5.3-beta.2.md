# TSUN Local 1.5.3-beta.2

This beta aligns the project communication with the successful real-device validation of **Sunology PLAY2** and makes the new cross-protocol alarm experience explicit.

## Sunology PLAY2 — validated

An independent Home Assistant installation on a real Sunology PLAY2 automatically discovered the device and completed TSUN Local setup successfully.

Validated path:

```text
Sunology PLAY2
  → LSW5BLE logger
  → TCP 8899
  → Solarman V5
  → sensor list 0x02B0
  → Modbus RTU FC03
  → TSUN Local / Home Assistant
```

The exact underlying TSUN MX hardware variant is intentionally not guessed; compatibility is tied to the confirmed local 02B0 protocol path.

## Clear-text alarms

The compact alarm interface introduced in 1.5.3-beta.1 is now highlighted consistently across the project:

- **Inverter alarm** — problem binary sensor.
- **Active alarms** — number of active alarm bits.
- **Active alarm names** — localized clear-text descriptions with stable protocol-position codes.
- **02B0 / PLAY2 example:** `Grid undervoltage (02B0-A014)` / `Sous-tension réseau (02B0-A014)`.
- Raw 02B0 ERR1–ERR4 registers remain available as disabled-by-default diagnostics.

This clear-text alarm catalogue is shared by 1511, 02B0 and 1097.

## Web and documentation

All inverter access remains local and read-only. No configuration, protection-setting, provisioning or control write is added.
