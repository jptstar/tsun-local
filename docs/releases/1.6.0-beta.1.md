# TSUN Local 1.6.0-beta.1

Released: 2026-09-02

This beta focuses on communication resilience for TSUN loggers with intermittent or marginal local-network connectivity. Adaptive behavior is **opt-in per micro-inverter**; existing installations keep the previous fixed polling behavior unless the new option is enabled.

## Added

- Add an optional **Adaptive polling** mode to each TSUN Local device.
- Back off progressively after real protocol communication failures and recover progressively after communication returns.
- Keep the existing **Micro-inverter online** state authoritative: the configured consecutive-failure threshold decides when the micro-inverter becomes offline, and the configured offline/night interval is used immediately at that point.
- Add chartable communication diagnostics for effective polling interval, adaptive state, adaptive reason, consecutive successes and adaptive backoff events.
- Add privacy-safe diagnostic counters for polling attempts, successes, failures and per-logger queue behavior.
- Add a dedicated FIFO request queue for each logger so requests to one logger remain serialized while unrelated micro-inverters can communicate independently.
- Serialize periodic logger Web/Wi-Fi metadata reads through the same per-logger FIFO queue as protocol polling.

## Fixed

- Bound and protect TCP stream shutdown for 02B0, 1097 and 1511 so a failed or hanging `wait_closed()` cannot turn an otherwise completed transaction into a communication failure or indefinitely hold the logger request gate.
- Prevent a slow or unavailable logger from blocking protocol polling for every other TSUN Local device.
- Keep adaptive polling state synchronized with the existing **Micro-inverter online** binary sensor.

## Wi-Fi and online-state semantics

- **Logger Wi-Fi signal is diagnostic only.** A weak signal does not slow a logger that is communicating successfully.
- A Wi-Fi value of `0` can be recorded as the diagnostic reason when a protocol request also fails, but Wi-Fi alone never marks the micro-inverter offline.
- **Micro-inverter online** remains based on successful local protocol polling and the configured consecutive-failure threshold, not on RSSI.
- The logger may remain connected to Wi-Fi at night while the inverter side is asleep or unable to answer telemetry requests; the two states are intentionally kept separate.

## Compatibility and regression policy

- Adaptive polling is disabled by default.
- Fixed polling keeps the existing normal, error-retry, offline/night and failure-threshold behavior.
- No protocol register map or telemetry scaling is changed by this beta.
- Public stable documentation remains on 1.5.4 while this prerelease is evaluated.
- English, French, German, Spanish, Italian, Dutch, Polish and Simplified Chinese translations are included.

## Safety

- TSUN Local remains strictly local and read-only.
- No inverter configuration, protection-setting, country/profile or control write is added.
