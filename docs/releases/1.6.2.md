# TSUN Local 1.6.2

TSUN Local 1.6.2 stabilizes daily-energy restoration and promotes the validated 1.6.2 beta work to stable.

## Critical daily-energy restore fix

- Restored Home Assistant energy states are now converted from the stored display unit (for example Wh) to TSUN Local's native kWh before they are reused.
- This prevents the 1.6.1 update/restart regression where a value such as `190 Wh` could be interpreted as `190 kWh`.
- AC and PV daily/total energy restoration uses the same unit-safe path for 1511, 02B0 and 1097.
- Clearly impossible 1.6.1 daily values already affected by the x1000 regression are repaired conservatively; plausible values are never guessed.
- Home Assistant local midnight remains the only displayed daily-energy boundary. Hardware/logger counter resets continue to be handled with total-energy deltas.

## Activity and diagnostics

- `communication_last_success` is published to the UI at most every five minutes while exact poll timing remains in diagnostics.
- Raw `*_raw` diagnostics and the last-success timestamp stay available but are hidden from normal UI visibility by default.
- Meaningful communication, adaptive polling, operating-state and decoded alarm entities remain visible.

## Country / grid profile

- Adds protocol-aware `country_profile` presentation as `code (native name)`.
- 1511 evidence includes `2 (Deutschland)`, `6 (Polska)` and `8 (France)`.
- 02B0 and 1097 keep their protocol-specific profile sources. Unknown values remain numeric rather than guessed.

## Alarm decoding

- MP3000 / 1511 `A030` (`8192 / 0x2000` in global alarm word 1) is decoded as **Low solar input**.

## Validation

The stable source is published only after the complete unit-test suite, HACS validation and Home Assistant Hassfest pass. TSUN Local remains local and strictly read-only.
