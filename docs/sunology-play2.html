TSUN Local
VALIDATED ON REAL SUNOLOGY PLAY2 HARDWARE

Sunology PLAY2 in Home Assistant — automatically, locally.

TSUN Local provides a direct, read-only local path from a compatible Sunology PLAY2 to Home Assistant. The validated installation was automatically detected by the normal integration flow.

What is validated?

A community tester installed TSUN Local against a real Sunology PLAY2 and reported that the PLAY2 was detected automatically and quickly. This moves PLAY2 from protocol research to validated Home Assistant compatibility for the tested hardware path.

✅ Automatic discoveryNormal TSUN Local discovery found the PLAY2 without requiring a manually entered IP address in the successful test.
✅ Direct Home Assistant integrationThe normal TSUN Local config flow completed successfully and created the device.
✅ Local read-only telemetry pathNo cloud service or proxy is required in the Home Assistant data path.
✅ 02B0 transportThe tested logger uses Solarman V5 on TCP 8899 carrying a 02B0 Modbus RTU response.

Validated local protocol path

Sunology PLAY2 → LSW5BLE logger → TCP 8899 → Solarman V5 → sensor list 0x02B0 → Modbus RTU FC03 → TSUN Local → Home Assistant
Field-tested logger firmware: LSW5BLE_17_02B0_1.08-D1. Sunology may ship different revisions under the PLAY2 commercial name, so TSUN Local still validates the detected local protocol at runtime.

Plug-and-play installation

  1. Install TSUN Local from HACS.
  2. Restart Home Assistant.
  3. Open Settings → Devices & services and add TSUN Local.
  4. Let automatic discovery find and identify the PLAY2 logger.

No proxy deployment. No cloud account required for the data path. No protocol selector. No manual IP in the validated automatic flow.

Alarms in readable text

The 1.5.3 beta extends human-readable localized alarm presentation to the 02B0 family used by the validated PLAY2 path. Known alarms are shown with a clear functional description while keeping a stable diagnostic code, for example Grid undervoltage (02B0-A014). Unknown positions remain visible with neutral wording instead of guessed meanings.

Why was a special PLAY2 probe needed before?

The dedicated read-only probe was used during protocol research to identify the logger transport and the explicit 02B0 sensor-list selector. TSUN Local 1.5.2 incorporated that result. For ordinary users, the recommended path is now the normal integration and automatic discovery.
