# macOS — premier lancement de TSUN Local Diagnostic

> 🟠 **TSUN Local Diagnostic n’est pas encore notarifié par Apple.** macOS peut donc bloquer son premier lancement.
>
> **Il n’est pas nécessaire de désactiver Gatekeeper ni la sécurité générale du Mac.**

1. Téléchargez la version correspondant à votre Mac :
   - **M1 / M2 / M3 / M4…** → **Apple Silicon**
   - **ancien Mac Intel** → **Intel**
2. Décompressez le fichier ZIP.
3. Essayez d’ouvrir **TSUN Local Diagnostic.app** une première fois.
4. Si macOS bloque l’application, cliquez sur **Terminé**.
5. Ouvrez ** → Réglages Système → Confidentialité et sécurité**.
6. Descendez jusqu’à la section **Sécurité**.
7. Cliquez sur **Ouvrir quand même** pour TSUN Local Diagnostic.
8. Authentifiez-vous avec votre mot de passe ou Touch ID, puis confirmez **Ouvrir**.

> 🟢 **Une fois l’application ouverte, c’est terminé.** Cette autorisation concerne uniquement TSUN Local Diagnostic ; les protections générales de macOS restent actives.
>
> Cette autorisation n’est normalement nécessaire qu’au premier lancement de cette version de l’application.

Ne lancez pas de commande visant à désactiver Gatekeeper globalement.
