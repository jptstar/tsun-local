# TSUN Local — Download statistics

This page tracks downloads of the **TSUN Local release package** for each stable version.

> [!IMPORTANT]
> These numbers are **download counts, not user counts**.
>
> A download can be an initial installation, an update, or a reinstall. The same installation can therefore contribute to several version counters over time.

## How to read these numbers

The per-version counter is useful for comparing how quickly new releases are adopted.

For example, if a new stable version approaches the download level of the previous stable release, it is a useful indication that users are following the update path.

It must **not** be interpreted as the number of unique users or active installations. A reliable active-installation metric would require a different data source.

## Data source

The counters above are generated dynamically from **GitHub Release asset download counts** using Shields.io and specifically track the `tsun-local.zip` package used by HACS.

No telemetry is added to TSUN Local for this page.
