Test your TSUN microinverter

TSUN Local 1.6.2 provides a privacy-safe, strictly read-only diagnostic for validating unlisted hardware and investigating local communication.

Choose one diagnostic

The Windows executable and full Python package use the same read-only diagnostic engine and anonymized report format.

Run the Python package

Extract the ZIP, open a terminal in the extracted folder and run:

python3 tsun_diagnostic_cli.py --full

The historical single-file tsun_dump.py remains available only as an advanced compatibility fallback.

Recommended workflow

Before capture, disable the affected TSUN Local config entry so two clients do not compete for the same local connection.
Run the diagnostic and complete the requested inverter model / quantity information.
Review and upload the anonymized report only after explicitly checking the consent option.
Re-enable TSUN Local when the capture is complete.

Privacy and safety

Strictly read-onlyNo inverter configuration writes, provisioning, reboot, reset or firmware-update actions.
Anonymized reportingLocal identifiers and credentials are removed or minimized before optional upload.
Explicit consentDirect upload is never automatic and consent is never remembered.
Traceable receiptA successful upload returns a TSL-... receipt and private-token view link.
