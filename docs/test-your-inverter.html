Run the full Python package

Extract the ZIP first, open a terminal in the extracted folder, then run the supported command-line diagnostic.

# macOS / Linux python3 tsun_diagnostic_cli.py --full # Windows py tsun_diagnostic_cli.py --full
Compatibility tool: tsun_dump.py remains available for existing workflows and advanced fallback use, but the full Python package is the normal cross-platform distribution.

Recommended workflow

Disable TSUN Local for the logger you are about to test so two clients do not compete for the same local connection.
Run the diagnostic and complete the requested inverter model / quantity information.
Review and upload the anonymized report only after explicitly checking the consent option.
Re-enable TSUN Local when the capture is complete.

Privacy and safety

The diagnostic is designed for validation, not configuration.

Strictly read-onlyNo inverter configuration writes, provisioning, reboot, reset or firmware-update actions are performed.
Anonymized reportingFull local IP addresses, serial identifiers and MAC addresses are redacted or minimized before optional upload.
Explicit consentDirect report upload is never automatic and the consent choice is never remembered.
Traceable receiptA successful upload returns a TSL-... receipt and a private-token link for the tester to inspect the submitted report.

What to send when validating new hardware

The most useful result combines the diagnostic with the exact commercial inverter model, detected protocol, firmware, number of PV inputs and whether PV/AC power and energy values look plausible.
