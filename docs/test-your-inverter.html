Your model may already be compatible

TSUN Local detects supported local protocol families, not only a fixed list of commercial model names. The validated families currently include 1511 and 02B0, while 1097 support remains experimental.

✅ An unlisted model does not mean an unsupported model.If your inverter exposes a supported local protocol, automatic discovery may already be enough.

Standalone diagnostic — now self-updating

The diagnostic channel is independent from Home Assistant integration releases. The current tools are Windows GUI 1.4.1 and tsun_dump.py 2.7.1. Starting with these versions, the same downloaded file checks the rolling diagnostic-latest release at startup and installs a newer verified diagnostic automatically.

One manual download, then automatic updates.Every replacement is checked with SHA-256 before it is installed. If GitHub or the Internet is unavailable, the current diagnostic continues to work and no replacement is performed.
Windows · TSUN-Local-Diagnostic.exe macOS / Linux · tsun_dump.py Diagnostic release & checksums
Python options: --no-update skips the startup update check for that run; --check-update checks whether a newer dumper exists and exits. Python 3.10+ is required.

Three simple steps

1Disable TSUN Local

Temporarily disable the affected config entry in Home Assistant to avoid two simultaneous polling sessions on the logger.

2Run the diagnostic

Windows users launch the portable EXE. macOS/Linux users run python3 tsun_dump.py --full.

3Share the JSON

Re-enable TSUN Local, then send the anonymized JSON and the Home Assistant diagnostic when available to dev@jptstar.com.

What the diagnostic investigates

The read-only engine discovers local TSUN loggers, identifies 1511 / 02B0 / 1097 protocol families, captures known-safe register ranges and gathers bounded passive logger metadata. It can recognize multiple Wi-Fi RSSI layouts in percent or dBm and, in full mode, test whether the logger answers the read-only `AT+WSDNS` DNS query without storing the returned DNS address.

✅ It worksReport the exact model and result so the hardware can be added to the validated compatibility list.
❌ It fails or becomes unavailableThe report preserves protocol evidence that can distinguish a register-range issue, logger response marker, firmware variant or communication behaviour.

Safety and privacy

The standalone diagnostic remains strictly read-only. It does not implement inverter configuration writes, submit logger forms, follow external links, or invoke reboot/reset/update pages.

Before publishing a report: the generated JSON is designed to exclude the full local host address, Monitor SN and complete inverter serial number, but it can contain production and energy readings. Review attachments before posting them publicly.
