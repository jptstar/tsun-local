TSOL-MX500 in Home Assistant — local monitoring with TSUN Local

The TSUN TSOL-MX500 is a validated reference device for TSUN Local’s GEN3 / 02B0 support and can be monitored directly on the local network from Home Assistant.

Validated compatibility

This page documents a real-hardware compatibility path, not a model-name assumption. TSUN Local still identifies devices from the local protocol exposed by the inverter/logger combination.

✅ Real-hardware validationThe MX500 is one of the reference devices used to validate TSUN Local’s 02B0 support.
☀️ PV telemetryVoltage, current, power and energy entities are exposed for PV inputs detected from the device.
⚡ AC telemetryAC voltage, current, frequency, power and energy are exposed where returned by the inverter.
🛡️ Read-only diagnosticsFirmware, inverter temperature and additional 02B0 diagnostics can be exposed without adding configuration writes.

Local protocol path

TSUN TSOL-MX500 → local network → GEN3 / protocol 02B0 → TSUN Local → Home Assistant
Protocol: 02B0 / GEN3. No inverter configuration writes are implemented.

Home Assistant setup

  1. Install TSUN Local through HACS.
  2. Restart Home Assistant.
  3. Add TSUN Local from Settings → Devices & services.
  4. Use automatic discovery when available, then verify the detected protocol and telemetry.

Validation evidence

TSOL-MX500 has been listed as validated 02B0 hardware since the protocol-family compatibility work shipped in TSUN Local 1.4.0. See the 1.4.0 release notes and the entity reference for protocol-specific details.
