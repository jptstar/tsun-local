Validated 02B0 compatibility

Real TSOL-MX450 hardware produced valid 02B0 telemetry, and the user subsequently confirmed Home Assistant compatibility. The older diagnostic's intermittent communication issues were associated with Wi-Fi connectivity, not an unsupported 02B0 protocol.

Home Assistant setup

  1. Install TSUN Local through HACS.
  2. Restart Home Assistant.
  3. Add TSUN Local from Settings → Devices & services.
  4. Use automatic discovery when available, then verify protocol 02B0 and that live AC/PV telemetry is plausible.
