TSOL-MX450 in Home Assistant — local 02B0 monitoring

TSOL-MX450 hardware responds on the supported local 02B0 protocol. An archived 1.5.4 Home Assistant diagnostic also reported intermittent malformed Modbus responses, so stable operation still needs an updated field check.

Real-hardware 02B0 evidence

The supported protocol and hardware identity are distinct: this 450 W inverter produced real local telemetry, but its intermittent connection history should remain visible rather than being mistaken for flawless operation.

✅ Captured protocolThe independent 02B0 dump captured 112 registers across three snapshots, including 12 successful Modbus read blocks.
☀️ 450 W signatureNominal and designed powers are both 450 W, consistent with the owner's TSOL-MX450.
🧩 Firmware V6.2.18The Home Assistant diagnostic identified GEN3 / 02B0 and firmware V6.2.18.
⚠️ Intermittent deviceThe archived TSUN Local 1.5.4 diagnostic reported repeated invalid frames. Users should retest with TSUN Local 1.6.2 or newer.

Local protocol path

TSUN TSOL-MX450 → local network → protocol 02B0 → TSUN Local → Home Assistant
Protocol: 02B0 was observed, not 02B2. The early device exhibited intermittent invalid Modbus responses. All TSUN Local requests are read-only.

What the diagnostics confirm

AC monitoringPreviously valid readings included 117.6 W AC, voltage, current, frequency and total AC energy.
PV decoding cautionAn older diagnostic version falsely inferred four inputs and implausible PV3 power from a 450 W unit. Do not assume four real PV inputs.
Connection resilienceSupported local 02B0 reads are implemented; success depends on logger response quality and firmware.
Validation follow-upRequest a fresh anonymized Home Assistant diagnostic if the device remains unavailable after updating.

Home Assistant setup

  1. Install TSUN Local through HACS.
  2. Restart Home Assistant.
  3. Add TSUN Local from Settings → Devices & services.
  4. Use automatic discovery when available, then verify protocol 02B0 and that live AC/PV telemetry is plausible.
