MS800 Balcony protocol findings

The existing 02B0 path has been observed on TSOL-MS800 Balcony hardware. A physical-label confirmation for the Y4Z variant was supplied in the community investigation #110; a separate 10 October 2026 report contains coherent 800 W / two-PV telemetry. Do not confuse that evidence with a confirmed 02B2 protocol: none has been demonstrated here.

🧩 Protocol02B0 / GEN3 / GEN3 PLUS. The earlier experimental 3026 hypothesis for Y4Z was rejected.
☀️ Power and inputs800 W rated power and two PV inputs in the October capture.
🔁 Read-only capture15/15 successful read blocks, 3/3 coherent snapshots and 144 raw registers.
📡 October loggerFirmware LSW5_SSL_02B0_1.05, profile 688:Tengsheng_G3, serial prefix Y00. The earlier labelled Y4Z hardware is a separate evidence trail.

Local monitoring path

TSOL-MS800 Balcony (reported hardware) → local network → protocol 02B0 → TSUN Local → Home Assistant (stability not yet confirmed)
Current status: valid 02B0 Modbus telemetry exists. Normal Home Assistant operation is not yet fully validated: the Y4Z tester also reported extended communication failures and unavailable entities after installing TSUN Local 1.6.2. There is no evidence here for 02B2 compatibility.

Home Assistant setup and verification

  1. Install TSUN Local through HACS and restart Home Assistant.
  2. Add the integration and verify the logger is reachable on local TCP port 8899.
  3. Confirm protocol 02B0 and check AC/PV entities over time rather than relying solely on a one-off dump.
  4. If entities become unavailable, send an anonymized Home Assistant diagnostic in issue #110.
