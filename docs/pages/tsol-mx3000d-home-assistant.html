GEN4 / 1097 compatibility evidence

The GEN4 / 1097 protocol is implemented in TSUN Local. Two real MX3000D diagnostic files confirm correct local register reads; these do not by themselves certify long-term Home Assistant operation on all firmware variants.

✅ Two real-device capturesBoth independent September 30 reports completed 30 of 30 read blocks and captured 216 distinct registers each.
☀️ Six PV inputsThe captured units report six PV channels and 3000 W nominal power, consistent with the MX3000D hardware signature.
🧩 Observed firmwareBoth units reported inverter firmware V3.2.68 on protocol 1097 / GEN4.
🛡️ Supported read-only pathTSUN Local implements 1097 telemetry locally without cloud relay, proxy or inverter configuration writes.

Home Assistant setup

  1. Install TSUN Local through HACS.
  2. Restart Home Assistant.
  3. Add TSUN Local from Settings → Devices & services.
  4. Use automatic discovery when available, then verify protocol 1097 and that live AC/PV telemetry is plausible.
